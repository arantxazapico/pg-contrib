# Contributions

I work as a cryptography researcher at the Ethereum Foundation.

My research is mainly focused on algebraic techniques for succinct arguments,
including SNARKs, vector commitments, lookup arguments, probabilistic proofs,
zero-knowledge proofs, and theoretical aspects of blockchains.
